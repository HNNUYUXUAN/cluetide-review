# Public-wallet review recording guide

Updated 12 October 2026. Start from [the public product](https://hnnuyuxuan.github.io/cluetide-app/release/). The wallet holder records the browser and extension confirmation windows continuously. Verify the captured video before submission.

1. Show the public URL, Connect Wallet, the connected account and BOT Mainnet 677.
2. Create a fresh task with a distinct designated reviewer. Show the roles and fixed demo target. Inspect and sign Register release; show its verified transaction and actual fee.
3. Prepare and export v1 with the exact artifact, source reference and checks actually performed. Sign Submit exact version and show its chain commitment.
4. Switch to the designated reviewer. Inspect the package and approve v1 through the wallet.
5. Switch to the proposer. Change the artifact to create v2 and show the two versions and distinct digests. Submit v2. Show that it awaits its own review and cannot use the old approval.
6. Obtain the reviewer's v2 approval. Switch to the executor. Check the online publication service and import the exact package before authorizing one start. Show the mainnet confirmation and unique attempt.
7. Publish the approved artifact. Download and inspect the actual output. Verify the signed receipt, artifact digest and chain commitment separately; record the receipt through the wallet if needed.
8. Show transaction links and actual gas fees. End recording and inspect the file for wallet windows, readable URL, both versions, real publication and final checks.

Suggested narration: “ClueTide binds a release approval to exact files and scope. The reviewer approved version one. After the agent changes the artifact, version two needs another approval. The controlled publisher consumes one valid authorization, writes the approved files, and signs a receipt. We verify the chain record, signature and published bytes separately.”
