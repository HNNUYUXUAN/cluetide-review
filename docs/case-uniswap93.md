# UNI 公开案卷读取说明

本产品使用[Uniswap proposal 93 公共快照](../data/cases/uniswap93/README.md)。原观察、采集脚本、来源署名与摘要均在同一案卷目录。

窗口为 Ethereum 24106368–24106388，主体为治理 Timelock，代币为 UNI。报告把1亿 UNI 的 Transfer、治理执行材料和相邻区块的 totalSupply 观察作为分别可核对的证据；Transfer 收款地址本身不能替代供给状态核读。

当前数据流和调查边界见[审阅指南](REVIEW.md)，文件来源与摘要见[来源说明](../SOURCE.md)。
