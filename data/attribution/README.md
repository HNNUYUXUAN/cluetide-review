This directory preserves the source license files, including bundled notices, under `licenses/python`, `licenses/npm` and `licenses/build`. ClueTide 自有代码采用 MIT 许可；第三方代码和材料按各自条款使用。本目录保留 Python、npm 和构建依赖的原始许可与 bundled notices；前端运行时许可随静态站点分发。

## 原始索引 / Source metadata

- [依赖来源索引.json](依赖来源索引.json): original dependency/source/license mapping, captured 2026-10-07.

The original project-authorization field records its historical state; the current ClueTide license is the root MIT license.

索引按原始日期、提交和锁文件范围解释，保留原字节。当前安装范围由本版锁文件确定。索引中的项目授权字段记录历史状态；本版 ClueTide 代码许可见根目录 LICENSE。
