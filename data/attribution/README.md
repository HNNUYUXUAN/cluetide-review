# Third-party attribution

The `licenses/` tree preserves original dependency licenses and notices byte for byte. The dependency source index records locked versions, public upstream URLs, license paths, and SHA-256 digests. These records retain their original provenance dates.

- [Dependency source index](依赖来源索引.json)
- [License verification index](许可索引核验.json)
- [Official distribution license readback](官方发行许可核读.json)

ClueTide code uses the root MIT license. Third-party code and materials retain their own terms. Public case folders separately identify source observations and interpretive summaries.
